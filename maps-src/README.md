# Старые карты для всех пользователей сайта

Сюда кладутся отсканированные карты с привязкой. GitHub сам нарежет их
на тайлы (вкладка Actions → «Нарезка старых карт», 5–30 минут), и карта
появится в списке «Старая карта поверх» у всех, кто открывает сайт.

## Как добавить

1. Откройте нужную папку (mende-1850, rkka-1941, shubert-3v, pgm) или создайте новую.
2. «Add file» → «Upload files», перетащите картинку листа и файл привязки
   с тем же именем: `лист5.jpg` + `лист5.map` (OziExplorer) или `.kml`.
   GeoTIFF с привязкой можно без отдельного файла.
3. «Commit changes».

Листы в одной папке склеиваются в один слой. Название и год слоя — в `layer.txt`.

## Ограничения

- Через сайт GitHub — до 25 МБ на файл (больше — через GitHub Desktop, до 100 МБ).
  Большой JPEG можно пережать до качества 80–85 % без потери читаемости.
- Весь сайт — около 1 ГБ. Выкладывайте свой район, а не всю губернию.
- Кладите только карты, которые можно распространять. Сами карты XIX века —
  общественное достояние, но условия сайтов, откуда взяты сканы и привязки, проверьте.
- Личные данные (файлы проекта, точки, выезды) сюда не кладите: репозиторий публичный.
