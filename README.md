# Поисковая карта старых мест

Открыть: https://alganin.github.io/karta/

Страница ищет урочища, исчезнувшие деревни, мельницы и усадьбы по данным OpenStreetMap
и накладывает старые карты на современные.

## Конфиденциальность

В репозитории только программа. Личных данных в нём нет и быть не должно.

- Точки, выезды, находки, фото и отметки хранятся только в браузере того устройства,
  на котором ими пользуются. На сервер они не отправляются, другие пользователи ссылки их не видят.
- Перенос между устройствами — только через файл проекта, который остаётся у владельца.
  Не загружайте файлы проекта и результаты распознавания в этот репозиторий
  (`.gitignore` блокирует их на всякий случай).

`ggc_ocr.py` — скрипт распознавания подписей на генштабовках и своих сканах старых карт, запускается на своём компьютере.

## Общие старые карты

Папка [`maps-src`](maps-src) — сюда кладутся сканы старых карт с привязкой (.map/.kml).
GitHub сам нарезает их на тайлы (`tools/build_tiles.py`, Actions → «Нарезка старых карт»),
и они появляются у всех пользователей в списке «Общие старые карты». Подробности — в `maps-src/README.md`.
